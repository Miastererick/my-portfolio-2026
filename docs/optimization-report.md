## 浏览器加载抽样

Chrome，桌面 1440×900；每页使用新的浏览器上下文，记录进入页面约 2.2 秒时浏览器收到的字节数。优化前后开发版的原始记录分别见 [`before-dev.json`](measurements/before-dev.json) 和 [`after-dev-warm.json`](measurements/after-dev-warm.json)，最终正式版记录见 [`after-production.json`](measurements/after-production.json)。开发版的 Next.js 调试脚本会计入请求，不代表线上资源量。

| 页面 | 开发版字体：前 → 后 | 开发版图片：前 → 后 | 首次内容绘制：前 → 后 |
| --- | ---: | ---: | ---: |
| 首页 | 17.07 MB → 0.48 MB | 原图尚未完成加载 → 0.47 MB | 316 ms → 132 ms |
| 商业项目分类 | 0.10 MB → 0.16 MB | 0.007 MB → 0.007 MB | 136 ms → 72 ms |
| 杭州亚运会项目详情 | 0.10 MB → 0.16 MB | 0.40 MB → 0.36 MB | 444 ms → 76 ms |

首页原先的字体传输量主要来自卡片中文字体；分类和详情页字体传输略增，是因为现在实际加载了正确的 HONOR Sans 字体。首页旧背景在基线采样结束时还没加载完成，因此表内首页图片数字不可直接比较。单独用相同的 Next.js 图片接口、1920 像素宽、质量 85 和浏览器 `Accept` 请求头测得：旧背景响应为 369 KB，新背景响应为 384 KB。**原始文件大幅缩小，但这张背景的实际浏览器传输量没有下降。**

上述绘制时间只是单次本机观察，受开发版编译和图片缓存影响，不能当作稳定的性能基准。正式版最终抽样的首次内容绘制分别为首页 112 ms、分类页 92 ms、详情页 68 ms。
